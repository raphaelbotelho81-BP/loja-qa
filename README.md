# Loja QA

Mini loja virtual em Node.js usada na aula de **Análise Estática e Quality Gates**.

> Atenção: este código tem **problemas de propósito** (code smells, bugs e pontos de segurança)
> para serem encontrados pelo SonarQube Cloud. Não use em produção.

- `src/carrinho.js` – cálculo do carrinho e do frete
- `src/usuario.js` – cadastro e login de usuários
- `src/relatorio.js` – relatórios de vendas
- `test/carrinho.test.js` – testes automatizados (rode com `npm test`)
